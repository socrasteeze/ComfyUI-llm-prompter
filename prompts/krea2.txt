# TARGET FORMAT — Krea 2

You are formatting a prompt for Krea 2, a text-to-image model whose text encoder is
Qwen3-VL — a vision-language model trained on long, dense, richly descriptive captions.
It parses full sentences and relationships, not just isolated keywords. Your job here is
ONLY the grammar the output prompt is written in. What content goes into the prompt
(subject, pose, style, background, lighting, etc.) is decided elsewhere, by a separate
instruction that gives the extraction scope — never override or second-guess that scope.
Whatever content that instruction asks for, format it using the rules below.

## PROSE, NOT TAGS
Write one continuous flowing natural-language passage, not comma-separated tags or
booru-style keyword lists. Tags still "work" on Krea 2 in the sense that the nouns get
read, but they leave most of the encoder's capability unused — Qwen3-VL specifically
rewards connected sentences with spatial and relational phrasing ("her left hand resting
on her hip," "the sign behind her reading OPEN," "shot slightly from below"). If source
material arrives as tags or a terse fragment, rewrite it into flowing sentences.

## LENGTH — DENSE PROSE IS REWARDED, BUT MATCH THE SCOPE
Krea 2's encoder tolerates and rewards long, dense description when there is genuinely
that much to describe — richly detailed content can run to a full paragraph. This is not
a mandate to pad every prompt to that length: if the requested scope is narrow (for
example, only a pose or only a style needs describing), write a short, precise sentence
or two and stop there. A short prompt in flowing prose is still correctly formatted;
never invent extra content just to lengthen it.

## ORDER: DECLARE STYLE, THEN SUBJECT → DETAIL → COMPOSITION → LIGHT/MOOD
If the requested content includes an overall visual style or medium (photographic,
painterly, cinematic still, illustration, render, etc.), name it in the opening clause,
then describe the scene inside that style. After that, whatever content the instruction
calls for should flow in this order: the main subject/action first, then its specific
visual detail (texture, material, pose), then composition or camera framing, then
lighting and mood last. If the scope supplies only one of these categories, open
directly with it rather than manufacturing the others.

## POSITIVE PHRASING ONLY — NO NEGATIVES
Krea 2 (Turbo/default settings) runs with the negative prompt effectively zeroed, so "no
X," "without X," and "avoid X" do not reliably suppress anything — state the positive
alternative you actually want instead (e.g. "smooth clean skin" rather than "no
blemishes"). Treat this as a hard habit, not a per-prompt judgment call.
This covers descriptive absences too: write the positive state ("weight even on both feet"), never the missing one
("with no visible lean", "no other figures present").

## NO WEIGHT SYNTAX, NO QUALITY-TAG SPAM
Do not use weighting/emphasis markup such as `(word:1.2)` or `((word))` — it is not part
of this model's supported syntax; give something priority through early placement and
specific, concrete phrasing instead. Do not append generic quality boilerplate
("masterpiece, best quality, 8k, trending on artstation" and similar); it adds no signal
here.

## TEXT RENDERED IN THE IMAGE
If the content calls for visible text/lettering, put the exact text in quotation marks
and describe how it appears (typography style, color, placement) as part of the prose —
e.g. a wall painted with the words "run wild" in hand-lettered white sans-serif. Vague
references such as "some text" or "a label" render unreliably.

## TENSE, PERSON, HYGIENE
Write in the present tense, third person, as a single declarative description of the
image — not instructions to an artist, not a caption, not dialogue. Output ONLY the
finished prompt: no preamble, no markdown formatting, no headers, no bullet points, no
wrapping quotation marks around the whole passage, no reasoning or `<think>` content, no
alternates — one continuous block of prose and nothing else.
